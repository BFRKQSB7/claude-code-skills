# 校对标准

## 实战铁律

1. **能批处理就批处理**：全项目 grep → 安全项 sed → 永远比逐章手改快 100 倍
2. **先扫高发区**：批量扫描后优先处理命中最多的弧线，低频区留到最后
3. **机翻垃圾直接重译**：读起来像未编辑机翻（语序混乱/假名残留/意义不明）→ 不校对，直接重译
4. **清单用删除线标记已处理**：批量 sed 清过的项目加 `~~删除线~~`
5. **不可批量替换的留待人工**：`这般/那般/、` 禁止 sed，逐章精校中逐条判断
6. **批量操作不计入 sessionChapterCount**：grep/sed 不占上下文，不触发 compact

## 校对三阶段

| 阶段 | 内容 | 耗时 | 覆盖 |
|------|------|------|------|
| **① 批量扫描** | 对全部章节跑 ②a ②b ③ ④ ⑤ ⑥ grep，不读正文 | 秒级/章 | 全章节 |
| **② 批量替换** | 对无歧义项批量 sed 替换 | 秒级/全章 | 仅安全项 |
| **③ 逐章精校** | 六步自检（含通读），处理需人工判断的项 | 分钟级/章 | 逐章推进 |

> ① → ② → ③ 顺序执行，不可跳过。批量扫描/替换期间 `sessionChapterCount` 减半计算。

### 阶段二：可批量 sed 替换的项

详见 `references/grep-patterns.md` 中「可批量 sed 替换的 ④ 项」和「可批量 sed 替换的 ②a/③ 项」两份清单。仅替换清单中的项——清单外的 `这般/那般/极是/好生/、` 等禁止 sed。

替换后不在校对清单中逐章记录（批量操作不计入逐章精校统计）。

### 阶段三：逐章精校（三步自检）

1. **① 通读**：逐句读，查读不通/结构崩溃/假名残留/重叠缺漏字，角色口吻一致性
2. **②-⑥ grep**：执行 `references/grep-patterns.md` 快速执行脚本。②a（残余这般/那般）和 ⑥（残余、）为逐章精校核心关注项
3. **修改**：逐处修正，每次修改后确认上下文通畅

每章完成后更新 `校对清单.md`（即使零命中也必须记录）+ `_context.json`（sessionChapterCount+1）。

### 决策与继续

- **count < 5**：输出简要摘要 + `count = N`，**同一轮回复中立即读下一章继续**
- **count ≥ 5**：先执行余量检查（回复变慢 / 引用 ≥3个 skill 文件 / 连续 ≥5 章未 compact）→ 命中则输出 `count = N，建议 compact`；未命中则输出 `count = N，继续？`

> ⚠️ count 输出不可跳过。每章完成后必须显式输出 `count = N`。即使 count < 5 也必须先输出再继续——连续 ≥2 章未输出视为规则失效。

## 直译句式检查重点

逐章精校时逐句检查以下模式（无法用 grep 批量处理）：

- **「的样子」**：～ようだ 直译 → 去掉或改写"似乎/看上去"
- **「便/就 + V」**：文言化信号 → 改为"就+V"（除非角色口吻需要）
- **「～一般/～般」**：比较后缀 → "～一样"（叙述文中一律替换）
- **「被认为是」**：～とされる 被动直译 → 转主动
- **「として」「わけ」「ことになる」**：日语语法词直译 → 去掉或意译

## 机翻垃圾识别（≥3项 → 整章重译）

| 信号 | 示例 |
|------|------|
| 日语假名残留 | 夏休み、ほんの数ヵ月、思い思いに |
| 日语敬体残留 | でした、ます、であーる |
| 英文未译词 | Hood、Defense、Infra |
| 重复字叠 | 過過ごす、通通、隠隠 |
| "便/这般那般"高密度 | 每段3次以上 |
| "在当场/在这其间"残留 | ～ている 直译 |
| 语法崩溃 | 主谓宾混乱、不通读 |
| 日语助词残留 | を、は、が、に、へ、と |
