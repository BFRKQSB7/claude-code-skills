# Grep 清单（校对·翻译自检共用，单一真相源）

> translate.md 和 proofread.md 都引用此文件。翻译后自检和校对时均使用这些 grep 表达式。

## ②a 白话文关键词（命中 = 不合格）

```bash
grep -nE "这般|那般|极是|好生|可恐|方才|一袭|确[^实认保]|诸般|须得|由理|何般|岂不|断断然|怎生|通身|一整个人|绝不允|临到末了|些些|颇为|决计|不拘|那等" 文件
```

| 命中词 | 替换 | 频率 | | 命中词 | 替换 | 频率 |
|--------|------|------|---|--------|------|------|
| **这般** | 这样/这么 | 🔴极高 | | **那般** | 那样/那么 | 🔴极高 |
| **方才** | 刚才 | 🔴极高 | | **极是** | 很是/非常 | 🔴高 |
| **颇为** | 相当/很是 | 🟡中 | | **决计** | 绝对/绝不会 | 🟡中 |
| 确然 | 确实 | 🟡中 | | 好生 | 非常/十分 | 🟡中 |
| 可恐 | 可怖/可怕 | 🟡中 | | 一袭 | 一件/一身 | 🟡中 |
| 不拘 | 不管/无论 | 🟡中 | | 那等 | 那种 | 🟡中 |
| 些些 | 些/一些 | 🟢低 | | 诸般 | 种种/各种 | 🟢低 |
| 须得 | 必须 | 🟢低 | | 何般 | 怎样/什么 | 🟢低 |
| 岂不 | 难道不 | 🟢低 | | 断断然 | 坚决 | 🟢低 |
| 怎生 | 怎么 | 🟢低 | | 通身 | 全身 | 🟢低 |
| 一整个人 | 整个人 | 🟢低 | | 绝不允 | 绝对不行 | 🟢低 |
| 临到末了 | 最后 | 🟢低 | | | | |

### 不可批量替换项（sed 禁止，需人工判断）

| 模式 | 原因 |
|------|------|
| `这般` | 可能→"这样"或"这么"，需看上下文 |
| `那般` | 可能→"那样"或"那么"，需看上下文 |
| `极是` / `好生` | 多义，需看上下文 |

## ②b 白话文句式（命中 → 逐条审视，大概率改写）

```bash
grep -nE "确然|决然|陡然|蓦然|豁然|骤然|悄然|淡然|断然|徒然|的罢|了罢|来着的|何故|何以|何曾|何等的|莫要|莫不|莫说|便也就是了|便也就|也便就|便这般|便那般|甚么|怎地|怎奈|未曾|极是|此[^时次后等前间处外人中刻番]" 文件
```

| 类别 | 文言特征 | 改为 | 频率 |
|------|----------|------|------|
| **然-后缀** | 确然/决然/陡然/悄然/淡然/断然/徒然 | 确实/绝对/突然/悄悄/淡淡/干脆/白白 | 🔴 |
| **便-X** | 便这般/便那般/便也就是了 | 就这样/就那样/也就是了 | 🔴 |
| **罢-句末** | 的罢/了罢 | 的吧/了吧 | 🔴 |
| **何-X** | 何故/何以/何曾/何等 | 为什么/凭什么/哪里/多么 | 🟡 |
| **莫-X** | 莫要/莫不/莫说 | 别/不要/更别说 | 🟡 |
| **未曾** | 未曾+V | 没+V+过 | 🟡 |
| **此-** | 此二人/此事（非固定词） | 这两人/这事 | 🟡 |
| **甚么/怎地/怎奈** | 近代白话残留 | 什么/怎么地 | 🟢 |

## ②c 整句语感（①通读时逐句检查，朗读测试）

| 信号 | 示例 | 改为 |
|------|------|------|
| 古典量词 | 一袭、一抹、一桩 | 一件/一道/一回 |
| "极为/极是/甚为" | 成熟韵味极为浓厚 | 满是/很有/非常 |
| "泛着" + 颜色 | 泛着紫调的礼服 | 紫色的礼服 |
| 密集"之" (一句3+) | 赴宴之礼的衣装 | 赴宴礼的衣装 |
| "者"名词后缀 | 立身者、竞者 | 的人 |
| "亦" 代替 "也" | 亦都在这 | 也都在这 |
| "确" 单独副词 | 确已/确是 | 确实已经/确实是 |
| "并非" | 并非什么寻常小馆 | 不是什么 |
| "似的/仿佛" + 文言 | 仿佛不知何故般 | 好像不知道为什么 |

## ⑤ 句式残留（命中 → 人工判断是否直译残留）

```bash
grep -nE "的样子|被认为|という|模様|わけ|ことになる|ものだ|として" 文件
```

| 命中 | 典型问题 | 改写方向 |
|------|----------|----------|
| 的样子 | ～ようだ 直译 | 去掉或改写为"似乎/看上去" |
| 被认为 | ～とされる 被动直译 | "被视作/视为"或转主动 |
| という | 残留假名 | 整句改写 |
| 模様 | ～もよう | "样子/情形/状态" |
| わけ | 理由/道理 直译 | 去掉或意译 |
| ことになる | 直译残留 | 去掉或"就会/便会" |
| ものだ | 直译残留 | 去掉或改写 |
| として | 直译残留 | "作为"或去掉 |

## ⑥ 标点残留（→ 逐条判断）

```bash
grep -n "、" 文件
```

枚举保留 `、`，其余日语语气停顿一律改为全角逗号 `，`。

## 错误模式集（校对实战积累）

### 日语残留（最高频）
掃除→打扫 | 洋服→服装 | 休暇→暑假 | 部活→社团活动 | 朝食→早饭 | 建物→建筑 | 全般→整体 | 绝叫→尖叫 | 阳炎→热浪 | 水着→泳装 | 立身出世→出人头地 | 夕食→晚餐 | 飲み物→饮料 | 留守→不在家 | 油断→疏忽 | 邪魔→碍事 | 迷惑→添麻烦

### 日语句式残留
- "～打招呼到" → "打招呼"
- "将脸向了～" → "将脸转向了～"
- "意识"作动词 → "在意"

### 重叠/缺漏字
被虫咬咬→被虫咬 | 脚边边→脚边 | 确凿定→确定 | 姑先且→姑且 | 跟本→根本 | 凑凑巧→凑巧 | 最要了紧→最要紧

### 错别字
一小嘬→一小撮 | 渡满→镀满 | 究意→究竟 | 珀琥→琥珀 | 自卖自擂→自吹自擂 | 顽笑→玩笑 | 餐卷→餐券 | 磅薄→磅礴 | 合衬→合身 | 护守→守护

### 词汇选择
失倾→失去 | 冶艳→妖艳 | 合称→相称 | 郁卒→郁闷 | 敬谢不敏→不太乐意 | 闷绝→痛苦不堪 | 决计→绝不会

### 机翻垃圾识别（≥3项 → 直接重译）
- 日语假名残留（夏休み、ほんの数ヵ月）
- 日语敬体残留（でした、ます）
- 英文未译词（Hood、Defense）
- 重复字叠（過過ごす、通通）
- "便/这般那般" 每段3次以上
- 日语助词残留（を、は、が、に）
