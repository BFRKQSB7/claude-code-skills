# 轻小说/日记 日语翻译完整规范

> **使用指南**：本文件是完整参考手册。日常翻译以 `translate.md` 速查卡为主，遇到以下情况再翻阅本标准：
> - 原文有方言（关西腔/京都腔等）→ §四
> - 拟声拟态词翻译不确定（尤其清浊音区分）→ §六
> - 外来语人名需追溯源语言 → §二
> - 文化梗/双关语处理 → §九
> - 译名优先级有争议（官方 vs 民间）→ §一
>
> 综合 Baka-Tsuki Project Conventions、Wikipedia ACG 命名常规、J-Novel Club、
> 轻之国度社区、NGA 翻译讨论、学术研究 整理

## 一、译名三级制度

| 优先级 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| **第一** | 官方译名 | 原作者/版权方直接指定的中文名 | 公式サイトの中国語表記 |
| **第二** | 正式译名 | 授权代理商/出版商使用的译名 | 台湾角川、天闻角川 |
| **第三** | 通用译名 | 民间流传最广、使用最多的译名 | 字幕组/汉化组翻译 |

- **大陆版权方名称 > 港澳台版权方名称 > 民间通用名称**
- **一地译名不得干涉另一地译名**，翻译目标地区决定译名选择
- 台版与大陆版译名冲突时，面向大陆读者的翻译应以大陆版权方为准，未引入则可用台版或自行翻译并标注

| 桜 | 樱 | 日本常用汉字→中文对应简体 |
| 円 | 圆 | 日本简化字→中文对应字 |

| 姫 | 姬 | 有对应则转换 |

> 日文汉字名字**直接转写为中文简体**是标准做法，不属于音译

### 2.2 假名 → 音译选字原则

> "尽量用精辟或帅气的字来表现，根据角色性格选择汉字的气质"

**推荐汉字库**（按气质分类）：

| 气质 | 可用字 |
|------|--------|
| 女性柔美 | 莉、娜、雅、丝、薇、蕾、蜜、妮、莎 |
| 女性活泼 | 琪、拉、玲、琳、希、可、乐 |
| 男性坚毅 | 雷、昂、凯、斯、特、尔、德、克 |
| 中性/知性 | 维、尔、斯、特、文、理 |

**长度参考**：
- ≤4 假名 → 直接音译
- 5-7 假名 → 可音译，可部分意译
- ≥7 假名 → 建议意译

## 四、方言与口癖处理

### 4.1 方言处理策略

| 日文方言 | 常见处理 | 说明 |
|----------|----------|------|
| 关西腔（関西弁） | 中文口语/北方方言 | や→だ，へん→ない |
| 东北腔（東北弁） | 可考虑东北话 | 不过度 |
| 京都腔（京言葉） | 文雅书面语 | 优雅委婉感 |
| 冲绳方言 | 加注说明 | 极度罕见 |

> **核心**："传达语感差异"比"精确对应"更重要

### 4.2 口癖/语尾处理

| 日文 | 中文 |
|------|------|
| ～にゃ / ～ニャ | ～喵 / ～呐 |
| ～でござる | ～是也 / ～的说（古风） |
| ～でありんす | ～地说 |
| ～だぜ | ～啦 / ～哦（男性） |
| ～だぞ | ～哦 / ～啦（男性） |
| ～かしら | ～呢 / ～吧（女性） |
| ～ですわ / ～ですの | 不硬翻，用大小姐口吻再现 |
| ～っす | ～的说 / 口语化（体育系） |

### 4.3 口癖翻译核心原则

> **不该硬翻，应突出角色说话口吻**。关键是把「ですわ」翻成什么不重要，重要的是**让读者感受到这是个大小姐在说话**。翻译结果必须符合角色身份。

**角色类型 → 口吻对照**：

| 角色类型 | 中文处理 |
|----------|----------|
| 大小姐（お嬢様） | 文雅敬语 + 句尾"呢/呀" |
| 活泼少女 | 多"啦/呐/呀" + 叠词 + "小～" |
| 冷酷型 | 省略语气词，短句为主 |
| 热血型 | "啦/啊/哦" + 感叹号 |
| 慵懒型 | 省略号多 + 拖长音"啊——" |
| 御宅族 | 融入网络流行语（"什么鬼""天啦噜"） |

## 六、拟声词与拟态词（オノマトペ）

### 6.1 基本翻译策略

| 策略 | 说明 | 示例 |
|------|------|------|
| AABB 叠词 | 表示持续或反复 | ふらふら→摇摇晃晃 |
| ABB 型 | 表示状态 | ザラザラ→粗糙糙 |
| AABC 型 | 表示重复动作 | ペコペコ→频频鞠躬 |
| 四字格 | 增强节奏感 | ゴロゴロ→无所事事 |
| 意译 | 传达含义 | トボトボ→垂头丧气 |
| 词性转换 | 形容词化 | ゴツゴツ→粗糙的 |

### 6.2 清音 vs 浊音（关键区分）

日语中清浊音成对拟声词含义截然不同：

| 清音（轻/小/美） | 浊音（重/大/脏） |
|------------------|------------------|
| ぽろぽろ→吧嗒吧嗒（细流） | ぼろぼろ→扑簌簌（不止） |
| ころころ→骨碌碌（小巧） | ごろごろ→轰隆隆（笨重） |
| とんとん→咚咚（轻敲） | どんどん→咚咚（重敲） |
| さらさら→沙沙（清爽） | ざらざら→粗糙（不光滑） |

> 翻译时必须**区分清浊音的情感色彩差异**，不可混用

| 日文 | 中文 | 场景 |
|------|------|------|
| ドキドキ | 怦怦直跳 | 心跳/紧张 |
| ワクワク | 兴奋不已 / 跃跃欲试 | 期待/兴奋 |
| イライラ | 焦躁不安 | 烦躁 |
| のろのろ | 慢吞吞 | 行动迟缓 |
| ぐっすり | 酣睡 / 沉沉睡去 | 熟睡 |
| ピカピカ | 闪闪发光 / 亮晶晶 | 光亮 |
| ベタベタ | 黏糊糊 | 粘腻 |
| ガタガタ | 摇摇晃晃 / 咯吱咯吱 | 不稳/颤抖 |
| ザワザワ | 嘈杂 / 骚动 | 人群喧闹 |

## 七、标点符号与排版规范

### 7.1 轻小说常用符号

| 符号 | 用途 | 形式 | 说明 |
|------|------|------|------|
| 对话引号 | `「」`（推荐）或 `""` | 全角 | `「」` 源自日系/中文竖排，醒目 |
| 嵌套引号 | `『』` | 全角 | 双层引用（引号内再引） |
| 省略号 | `……` | 全角六点 | **禁止** `…`（三点）或 `......` |
| 破折号 | `——` | 两个全角 | 拉长音/中断，禁止英文 `—` |
| 浪纹线 | `～` | 半角 | 语气延长 |
| 顿号 | `、` | 全角 | 中文并列（非逗号） |
| 书名号 | `《》` | 全角 | 书名/作品名 |
| 间隔号 | `·` | 全角 | 外国人名分隔 |

### 7.2 全角 vs 半角

| 规则 | 说明 |
|------|------|
| **中文标点一律全角** | ，。？！：；（）《》「」『』 |
| **英文/数字标点半角** | , . ? ! : ; ( ) |
| **中文标点后不加空格** | 英文标点后才加 |
| **中西文间加半角空格** | `中文 English 中文`，提升可读性（盘古之白） |

### 7.3 轻小说特殊排版惯例

1. **对话分行**：每个角色的对话建议独立成段
2. **引号拆开**：对话中间插入动作描写时可拆引号——
   ```
   「我爱你，」她直视着他，「这是我的事。」
   ```
3. **心理独白**：不加引号或使用 `（）`（全角括号）
4. **书名号间不加顿号**：`《进击的巨人》《鬼灭之刃》`（非《进击的巨人》、《鬼灭之刃》）

### 7.4 常见符号错误

| 错误 | 正确 |
|------|------|
| `......` | `……` |
| `...` | `……` |
| `你好.` | `你好。` |
| `啊—` | `啊——` |
| `苹果,香蕉` | `苹果、香蕉` |
| `"你好"`（半角） | `"你好"`（全角） |

### 7.5 日→中逗号转换原则

日语逗号（読点「、」或コンマ「，」）与中文逗号「，」的**功能本质不同**：

| 维度 | 日语「、」「，」 | 中文「，」 |
|------|------------------|-----------|
| 功能 | 语气停顿/呼吸节奏 | 语法结构划分 |
| 密度 | 自由（受作者个人习惯影响大） | 受GB/T 15834规范约束 |
| 位置 | 可出现在任何想停顿处 | 固定语法位置 |

**为什么不能照搬日语逗号：**
- 日语是 S-O-V 语序，动词在句末，句中需要逗号帮读者"暂存"前面的信息——逗号是必要的认知缓冲
- 中文是 S-V-O 语序，信息按自然顺序展开——过多的逗号反而打断阅读流畅度
- 日语句子可以拖得极长（多层从句嵌套），中文习惯拆短

**转换三步骤：**
1. **忽略日语逗号**——读完整个句子（到「。」），只关注语法结构和语义
2. **按中文语法重建**——只在以下位置加中文逗号：
   - 较长的主语之后
   - 句首状语之后
   - 复句内各分句之间
   - 插入语、称呼语前后
3. **朗读删减**——读一遍，删掉导致"一顿一顿"感的冗余逗号。日语6个逗号→中文3个左右为正常比例

**典型错误（实战中发现）：**

| 错误 | 原因 | 修正 |
|------|------|------|
| "只好便，就这么半败半降地" | 日语原文有停顿，照搬为逗号 | "只好便就这么半败半降地" |
| "怯怯己斜的，落去了身晃着" | 日语状语后加逗号 | "怯怯地斜着身子晃落去" |
| "哗啦拉，全在了上头码" | 拟声词后照搬日语逗号 | "哗啦啦全都码在了上头" |

**核心原则：写完一句中文后，如果逗号前后的内容读起来是连贯的、一口气说完更自然的，就去掉逗号。中文逗号是"不得已才加"（语法需要），不是"想停就加"（语气需要）。**

## 九、文化梗与双关语

### 9.1 处理策略

| 优先级 | 方法 | 适用场景 |
|--------|------|----------|
| 1 | 意译（找中文对应梗） | 有通用文化对应 |
| 2 | 意译 + 译者注 | 有日本独特文化背景 |
| 3 | 直译 + 译者注 | 完全不可译 |
| 4 | 保留原文 + 注 | 极度特殊（如和歌、俳句） |

### 9.2 译者注格式

**推荐格式**：
```
① [译注：……]  ← 简短说明加句尾
② 脚注形式（适合长注），放置在段落末尾
```

**何时加注**：
- 日本文化特有事物（如「花火大会」「おせち料理」）
- 双关语/谐音梗无法用中文再现时
- 作品内梗/前作伏笔影响理解时
- 历史/神话引用需背景知识时

**何时不加注**：
- 可意译传达的日常文化梗
- 不影响主线的背景细节
- 读者普遍了解的内容

## 十、对话与独白处理

> 💡 日常速查 → `translate.md` 翻译策略-对话加主语/去机翻味

### 10.1 对话标签

- **不要擅自添加"××说道"**——被视为"随意增减原文内容"
- 靠**语气和语境**让读者分辨说话人
- 仅在原文有对话标签时才对应翻译

### 10.2 内心独白

- 日轻常有大段内心独白，保留其风格
- 原文无引号的独白 → 不加引号
- 原文用了「」的 → 保留或转中文「」
- 心理描写可用 `（）` 全角括号表示小声嘀咕

### 10.3 对话中的动作穿插

```
日文：
「……そうか」彼女はうつむいた。
→ 中文：
"……这样啊。"她低下了头。
```

动作可独立成句，不必硬塞进引号。

### 11.1 时态

| 类型 | 时态 |
|------|------|
| 叙述/描写 | 过去时 |
| 对话 | 现在时（自然口语） |
| 内心独白 | 现在时 |
| 日记体 | 过去时为主 |

### 11.2 日记体特别注意

- 保留日期行格式
- 保留第一人称视角
- 保留口语化/非正式表达
- 保留情感标记（www、……、——等）
- **「」对话标记保留**，不做西化引号转换

### 11.3 第一人称 vs 第三人称

- 第一人称（私/僕/俺）→ 我/在下/本大爷（按性格）
- 「俺」不一定翻译为"老子"，需结合角色——热血型可用 "本大爷"，普通型用 "我"
- 「僕」→ 礼貌型"我"，幼年角色可用"人家"

## 十二、禁止事项

> 💡 高频禁止事项速查 → `translate.md` 禁止事项速查（6条），此处为完整清单

| 禁止行为 | 原因 |
|----------|------|
| 擅自改变叙事顺序 | 破坏原文结构 |
| 添加原文没有的信息 | 不尊重原作 |
| 删减"难翻译"的内容 | 信息遗漏 |
| 前后译名不一致 | 读者困惑 |
| 所有敬语都译"桑" | 过度日化 |
| 把「高校」译成"高校" | 应译为"高中" |
| 把「生徒」译成"生徒" | 应译为"学生" |
| 把「担任」译成"担任" | 应译为"班主任" |
| 擅自判断角色性别 | 错误引导读者 |
| 纯机翻不润色 | 质量不可接受 |
| 日语式倒装句原样保留 | 不符合中文习惯 |
| 滥用译者注打断阅读 | 破坏节奏 |
