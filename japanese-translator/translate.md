# 翻译标准

## 核心原则

1. **保留格式** — 换行/分段/`「」`对话/`（）`独白/`……``——` 不变
2. **名词统一** — 译名全文一致
3. **去机翻味** — 消解日语句式，不擅自加「说道」
4. **用词通俗** — 选常见词，避免生僻字

## 翻译策略

- **长定语拆短**：日语"～という彼女"→"她……"，核心名词提前
- **被动改主动**：日式被动态→中文主动表达
- **对话加主语**：日语靠口癖辨人，中文需适当标注说话者
- **语气词节制**：不机械直译「ね」「よ」「まあ」
- **日式倒装句改写**：日语 S-O-V → 中文 S-V-O，动词提前
- **译文应像原创中文**：读起来不应有"翻译感"

## 译名处理（翻译前执行）

1. 读原文 → 提取不在 `翻译标准.txt` 中的新名称
2. 根据 `references/translation-standards.md` §二拟定译名
3. **提交用户确认**（日文原名 + 建议译名 + 角色身份）
4. 确认后追加到 `翻译标准.txt`，统一翻译全章

> **不可跳过**——即使置信度极高也不得自行决定。

## 标点速查

| 规则 | 正确 | 错误 |
|------|------|------|
| 省略号 | `……`（全角六点） | `...` / `......` |
| 破折号 | `——`（两个全角） | `—` / `--` |
| 对话引号 | `「」` | 西式 `""`（非对话可用） |
| 中文标点 | 全角 `，。？！：；（）` | 半角 |
| 中西文间 | 加半角空格 `中文 English` | 密接无空格 |
| 日式顿号 | `，`（全角逗号） | `、`（仅枚举可用） |

### 逗号原则

日语「、」≠ 中文「，」。日语逗号表示语气节奏，中文逗号标示语法结构。**翻译时必须读到句号「。」再从语法层面重建中文标点，不可照搬日语逗号位置。** 日语6个逗号 → 中文只需3个左右。

> 完整标点规范、方言、口癖、拟声拟态词等 → `references/translation-standards.md`

## 禁令速查（高频疏漏）

| 禁止 | 正确 | 原因 |
|------|------|------|
| 「高校」→"高校" | →"高中" | 同形异义词 |
| 「生徒」→"生徒" | →"学生" | 同形异义词 |
| 「担任」→"担任" | →"班主任" | 同形异义词 |
| 添加"××说道" | 靠语气/语境辨人 | 原文有的才译 |
| 日语倒装原样保留 | S-O-V → S-V-O | 不符合中文习惯 |
| 纯机翻不润色 | 每句检查自然度 | 质量不可接受 |
