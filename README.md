# Claude Code Skills

> 个人自用 Claude Code skills 集合与备份

## 技能清单

| 技能 | 说明 |
|------|------|
| **ai-model-recommender** | 按硬件与用途推荐 AI 模型 |
| **improve** | 主动学习 + 避坑 + 反省的代码开发工作流，100+ bug 模式 |
| **japanese-translator** | 日文轻小说翻译工作流（JP→ZH） |
| **minimax-h3** | MiniMax H3（海螺）视频提示词改写器：T2VA/I2VA/FL2VA/L2VA/Ref2VA 五模式 + 本地 ComfyUI 成人内容实跑坑 |
| **pinokio** | Pinokio 应用发现与运行时控制（pterm）+ 本地 AI 工具安装排错：llama.cpp 启动器/.bat、Open WebUI、SearXNG、多模型切换 |
| **playwright-cli** | 浏览器自动化与 Playwright 测试 |
| **ppt-master** | PowerPoint / 演示文稿生成与设计系统 |
| **skill-creator** | 创建新的 Claude Code skills |

## 使用方式

克隆到 `~/.claude/skills/`：

```bash
git clone https://github.com/BFRKQSB7/claude-code-skills.git ~/.claude/skills/
```

或克隆到别处后，用 symlink 单独链接某个 skill。

## 自动更新

```bash
cd ~/.claude/skills && git pull
```
