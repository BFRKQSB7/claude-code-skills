# Claude Code Skills

Personal collection of custom Claude Code skills. Self-use backup.

## Skills

| Skill | Description |
|-------|-------------|
| **AI-install-and-fix** | Local AI tool installation & troubleshooting. Pinokio, Open WebUI, llama.cpp, SearXNG |
| **ai-model-recommender** | AI model recommendations based on hardware & use case |
| **gepeto** | 1-click launcher builder for Pinokio apps |
| **improve** | Code development with active learning & self-improvement. 100+ bug patterns |
| **japanese-translator** | Japanese light novel translation workflow (JP→ZH) |
| **minimax-h3** | MiniMax H3 (海螺) 视频提示词改写器：T2VA/I2VA/FL2VA/L2VA/Ref2VA 五模式 + 本地 ComfyUI 成人内容实跑坑 |
| **pinokio** | Pinokio app discovery & usage |
| **playwright-cli** | Browser automation & Playwright testing |
| **ppt-master** | PowerPoint/presentation generation & design system |
| **skill-creator** | Create new Claude Code skills |

## Usage

Clone into `~/.claude/skills/`:

```bash
git clone https://github.com/BFRKQSB7/claude-code-skills.git ~/.claude/skills/
```

Or clone elsewhere and symlink individual skills.

## Auto-update

```bash
cd ~/.claude/skills && git pull
```
